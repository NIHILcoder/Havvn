# Havvn

[![Release](https://img.shields.io/github/v/release/NIHILcoder/Havvn?label=Release&color=e25117)](https://github.com/NIHILcoder/Havvn/releases/latest)
[![Downloads](https://img.shields.io/github/downloads/NIHILcoder/Havvn/total?label=Downloads&color=orange)](https://github.com/NIHILcoder/Havvn/releases)
![Platform](https://img.shields.io/badge/Platform-Windows%20·%20macOS%20%2F%20Linux%20planned-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Built with](https://img.shields.io/badge/Electron%20%2B%20React%20%2B%20Transmission%20%2B%20WebTorrent-informational)

**Приватный P2P-хаб без собственных серверов, который умеет работать с BitTorrent.**

Havvn (ранее TorrentHunt) — полноценный торрент-клиент, но загрузки — лишь его основа.
Он помогает делать то, чего обычно не умеют классические клиенты, напрямую между
участниками: **без серверов приложения, учётных записей Havvn и хранения в облаке**.

- 📺 **Смотрите где удобно.** Передавайте торрент на телефон, ноутбук или телевизор
  *прямо во время загрузки*. Форматы, которые браузер не поддерживает, преобразуются на лету.
- 🔗 **Делитесь ссылкой.** Отправляйте завершённую загрузку прямо в **браузер** друга:
  ему не нужно устанавливать приложение или создавать аккаунт.
- 👥 **Приватные комнаты для друзей.** Создайте **комнату** по приглашению:
  файлы участников синхронизируются в общую папку, а **чат защищён сквозным шифрованием
  и цифровыми подписями**. Соединения могут проходить через других участников,
  поэтому комнате не нужна собственная серверная инфраструктура.
- 🎮 **Играйте вместе.** Комната может стать **приватной локальной сетью** для игр
  через интернет. В ней же можно запустить **выделенный игровой сервер** —
  без аккаунтов и стороннего сервиса размещения.
- 🎙️ **Общайтесь голосом.** Голосовые комнаты без серверов приложения,
  **нейросетевое шумоподавление**, **демонстрация экрана** с системным звуком
  и эхоподавлением, **глобальная клавиша push-to-talk**.
- 🛡️ **Знайте, что видят пиры.** Панель приватности показывает ваш внешний IP,
  провайдера и состояние VPN, предупреждает об утечках IP и поддерживает kill-switch.

Источники поиска и ленты вы добавляете сами. Всё работает на вашем компьютере и
напрямую между участниками: **разработчик не обслуживает серверы, а эксплуатация
приложения ничего не стоит**. Публичные WebRTC **трекеры обнаружения участников**
помогают установить первоначальное соединение; они не передают файлы или открытое
содержимое. В «Настройки → Общий доступ» можно указать **свои трекеры**.
Обнаружение в сети также использует STUN; поиск обращается к вашим источникам,
а дополнительные функции, например проверка IP и провайдера, — к соответствующим сервисам.
Приложение построено на Electron, React, встроенном нативном движке Transmission и WebTorrent.

> **Только законное использование.** Havvn не включает источники поиска материалов,
> защищённых авторским правом. Единственный предложенный источник — RSS-лента
> Creative Commons / открытого ПО FOSS Torrents — **выключен по умолчанию**.
> Остальные источники и ленты добавляете вы; ответственность за загрузки и раздачи
> остаётся на пользователе.

## Скачать

Последний установщик для Windows доступен на
**[странице релизов](https://github.com/NIHILcoder/Havvn/releases/latest)**.

Этот README описывает текущую ветку `main`. Последний опубликованный релиз может
ещё не включать все перечисленные функции — сверяйтесь с его описанием.

### Проверить загрузку

Каждый релиз проверяется через [VirusTotal](https://www.virustotal.com/) и сопровождается
контрольной суммой SHA-256; результаты указаны в описании релиза. SmartScreen может
показать предупреждение «неизвестный издатель». Проверка контрольной суммы позволяет
убедиться, что загруженный файл совпадает с опубликованным.

```powershell
Get-FileHash .\Havvn-Setup-<version>.exe -Algorithm SHA256
```

Сравните результат с SHA-256 в соответствующем релизе GitHub.

## Возможности

### Загрузки

- **Встроенный нативный движок Transmission** для быстрых и проверенных передач,
  с резервным движком WebTorrent, который также обеспечивает комнаты и ссылки общего доступа.
- Добавление через **.torrent, magnet-ссылку или перетаскивание**: поддерживаются
  локальные файлы и URL `.torrent`. Можно **искать прямо из раздела загрузок**,
  не выходя из процесса добавления.
- Пауза, возобновление, удаление с возможностью удалить файлы, повтор неудачных загрузок.
- **Выбор файлов и приоритетов**, последовательная загрузка, общий лимит скорости.
- **Ограничение отдачи по умолчанию**: в новых профилях обычные торренты делят
  общий лимит **1024 КБ/с (1 МиБ/с)**. Он меняется в «Настройки → Подключение»;
  существующие профили сохраняют свои значения. Дополнительная адаптивная отдача
  снижает скорость при росте сетевой задержки.
- **Лимиты рейтинга и времени раздачи**, добавление и удаление трекеров у отдельных торрентов.
- **Остановка и возобновление раздачи** отдельно от паузы незавершённой загрузки:
  готовые файлы остаются в списке, и их можно снова раздавать.
- **Предупреждения трекеров** отделены от ошибок передачи: отказ одного трекера
  не превращает работающую загрузку в ошибку.
- **Категория и добавление на паузе** доступны в диалоге добавления, поиске и RSS.
  Категории — ваши группы загрузок, а не фильтры содержимого сайта-источника.
- Категории, поиск, фильтрация, сортировка, обычный и подробный виды списка.
- Двойной щелчок по `.torrent` открывает системный диалог «Открыть с помощью»:
  торренты не добавляются молча.

### Поиск контента

- **Подключаемые источники поиска**: **Jackett**, **Prowlarr (Torznab)**,
  собственный JSON API или **локальный Python-скрипт**. Встроенных индексаторов нет.
  Результаты появляются по мере ответа источников; поиск можно отменить,
  а одинаковые торренты объединяются. Выбирайте файлы, копируйте magnet-ссылку,
  открывайте страницу раздачи или добавляйте торрент на паузе в свою категорию.
  Неудачный источник можно проверить повторно, сохранив остальные результаты.
  Комментарий `th-plugin` позволяет скрипту сообщить название и необходимые данные
  авторизации заранее — см. [плагины поиска](docs/search-plugins/).
- **Сравнение вариантов релиза**: группировка одинаковых фильмов и серий,
  раскрытие вариантов, уточнение по параметрам релиза и отметки уже добавленных
  или завершённых торрентов. Сохраняйте предпочтения по разрешению, языку аудио,
  озвучке, максимальному размеру и минимальному числу сидов, чтобы подходящие
  варианты показывались первыми. Характеристики определяются по названиям релизов;
  неизвестные данные не выдаются за подтверждённые.
- **Подключение для каждого источника**: системное подключение с прокси/VPN,
  прямое подключение, общий профиль HTTP/SOCKS5-прокси и доверенные зеркала.
  Совместимые Python-плагины используют Havvn Network SDK. **«Войти на сайт»**
  открывает отдельное окно браузера: войдите в аккаунт, пройдите проверку сайта
  и закройте окно. Сессия сохраняется для поиска и получения `.torrent`.
  Расширения из Chrome/Edge автоматически не применяются.
- **RSS с правилами**: правило следит за выбранными лентами или всеми сразу,
  учитывает включаемые и исключаемые слова или регулярное выражение, размер,
  число сидов и возраст публикации. У правила свои папка, категория и режим паузы.
  Сопоставление серий оставляет **одну копию каждой серии**, даже если её публикуют
  разные релиз-группы. Ленты импортируются и экспортируются в **OPML**.
  Для новых элементов можно включить уведомления. Скрытые элементы запоминаются,
  поэтому правило не скачает их снова. Автоматически добавляются только публикации,
  появившиеся после подписки, а не весь архив. Предложенная лента FOSS
  **выключена по умолчанию** и не создаёт фонового трафика до включения.

### Просмотр и прослушивание

- **Встроенный плеер** воспроизводит файл *во время загрузки*.
  Музыку и видео можно **вынести в отдельное окно** с оформлением приложения
  и вернуть обратно; позиция, пауза и громкость сохраняются.
- **Настройки звука**: пятиполосный эквалайзер с пресетами, выравнивание громкости,
  повтор, перемешивание и выбор устройства вывода. Настройки сохраняются между
  треками, окнами и запусками.
- **Субтитры**: встроенные текстовые дорожки и отдельные `.srt`, `.ass`, `.vtt`
  преобразуются в WebVTT на лету и отображаются поверх видео.
- **Сохранение предпочтений плеера**: языки аудио и субтитров, режим субтитров,
  размер, цвет, фон и сдвиг по времени, а также выбранные дорожки для каждого файла.
- **Диагностика воспроизведения**: этап запуска, преобразования или буферизации,
  непрерывный буфер впереди, скорость торрента и пиры. При перемотке в незагруженный
  участок плеер ждёт данные; процент загрузки не равен доступному буферу видео.
- **«Продолжить просмотр»**: локальная история с продолжением, запуском сначала,
  переходом к следующей серии, отметкой «просмотрено», удалением записей и очисткой.
  Позиция сохраняется при перемотке, перекодировании, смене аудиодорожки и переходе
  между основным и отдельным окном. История не восстанавливает удалённые файлы
  и не возобновляет остановленные загрузки автоматически.
- **Предзагрузка следующей серии (Classic/WebTorrent)**: по желанию скачивается
  ограниченный начальный участок следующего файла ближе к концу просмотра.
  Приоритет остаётся у текущего видео; на паузе, при перемотке или нехватке буфера
  предзагрузка останавливается. Native/Transmission пока не поддерживает эту функцию.
  Для исключённых файлов требуется отдельное согласие.
- **Внешние плееры**: готовый файл открывается в системном плеере или установленном
  **VLC / mpv**. VLC и mpv могут играть незавершённые файлы через проверенный локальный
  поток, пока Havvn работает, и начинать с сохранённой позиции.
  **mpv передаёт прогресс обратно в историю**, пока Havvn открыт; VLC и системный
  плеер обратную передачу позиции не поддерживают.
- **Перекодирование на лету**: форматы, которые браузер не декодирует
  (mkv, HEVC, AVI и другие), преобразуются встроенным ffmpeg; внешний плеер не обязателен.
- **Просмотр на другом устройстве в локальной сети**: кнопка показывает QR-код
  и ссылку. Откройте её на телефоне, планшете или ноутбуке в **той же Wi-Fi-сети**
  и смотрите с **перемоткой**, включая неподдерживаемые браузером кодеки.
  Адаптивный HLS передаётся прямо с вашего ПК, без облака и установки на втором устройстве.
- **Трансляция на телевизор**: поиск Chromecast / Android TV / Google TV в сети,
  воспроизведение с управлением паузой, продолжением и остановкой.
- **Удалённый просмотр (экспериментально)**: поток с перекодированием через WebRTC
  на устройство *за пределами вашей сети*.

### Создание и общий доступ

- Создание торрентов из файлов и папок по одному или пакетно, свои трекеры,
  приватный флаг и немедленное начало раздачи.
- **Ссылки мгновенного доступа**: передавайте завершённую загрузку любому человеку
  в браузер через WebRTC, без установки на его стороне; короткие ссылки и QR-коды.
- **Вход в комнату через браузер**: ссылка из диалога приглашения открывает чат,
  голос и совместный просмотр в Chrome, Edge или Firefox. Гостю не нужна установка,
  а вы оставляете Havvn открытым. Зашифрованные файлы, виртуальная сеть,
  игровой сервер и запись файлов доступны в настольном клиенте.
- **Комнаты для друзей**: создайте приватную группу с удобным кодом приглашения.
  Файлы распространяются между участниками в общую папку. WebRTC помогает им
  найти друг друга и синхронизировать список файлов и присутствие;
  **чат со сквозным шифрованием AES-256-GCM** использует ключи, полученные из кода.
- **Интерфейс комнаты**: три области — участники и голос, сцена, чат —
  с разделителями, запоминающими ширину. **Вынесите любую панель** (чат, голос,
  файлы, сеть, сервер) в отдельное окно на второй монитор: звонок и загрузки продолжаются.
- **Сквозное шифрование комнат**: включается при создании. По сети передаётся
  **только шифротекст**; файлы шифруются на диске до раздачи и расшифровываются
  после загрузки. Ключ содержимого передаётся в **конфигурации, подписанной владельцем
  (Ed25519)**. Одного кода приглашения недостаточно, чтобы подменить конфигурацию
  или ключ. Код отмечает комнату как зашифрованную, чтобы новый участник не начал
  случайно раздавать открытые данные.
- **Организация общей папки**: разделы с папками, перетаскивание на оба уровня,
  **автозагрузка по папкам** с наследованием настроек раздела и комнаты
  или ручная загрузка отдельных файлов.
- **Работа с файлами**: контекстные меню, действия при наведении, фильтры,
  настройки вида, сортировка и запоминание свёрнутых разделов, подсветка поиска,
  **миниатюры изображений с просмотром**, открытие папки и общий размер.
  **Виртуализация списков** сохраняет отзывчивость больших комнат.
- **Совместный просмотр и музыка**: откройте общий файл в плеере комнаты
  и включите совместный режим. Воспроизведение, пауза и перемотка синхронизируются,
  поздние участники переходят к текущей позиции. Для музыки есть обложка из
  **ID3-тегов**, **спектр WebAudio**, общая очередь с автопереходом и реакции-эмодзи.
- **Просмотр до завершения загрузки** в плеере комнаты: для комнат без шифрования
  файлов и форматов, поддерживаемых браузером.
- **Профили участников**: подписанные профили с цветами имени, статусом и
  генерируемыми локально аватарами. Данные не загружаются на сервер;
  **карточка профиля** открывается из списка участников или сообщения.
- **Предпросмотр приглашения**: участники, число файлов, общий размер,
  активность голосового чата и заметная кнопка копирования.
- **Передача владения**: **подписанная цепочка передачи** позволяет проверить
  нового владельца комнаты.
- **Настройки каждой комнаты**: автоматическая или **ручная загрузка** файлов,
  свои **ограничения загрузки и отдачи**.
- **Подписанный чат**: каждое сообщение **подписано Ed25519** и связано с личностью
  участника. Знание кода приглашения не позволяет писать от чужого имени.
  Локальная история чата **зашифрована на диске**. Для кода есть многострочный ввод,
  отступы по Tab и **блоки кода** с тройными обратными кавычками и копированием.
- **Соединение между сетями без собственной инфраструктуры**: прямые соединения,
  IPv6 и STUN покрывают обычные случаи. Недоступные напрямую участники автоматически
  соединяются **через другого участника**, сохраняя сквозное шифрование.
  Для сложного NAT можно добавить **свой TURN-сервер**; достаточно настройки
  у одного участника. Видно, установлен ли **прямой или ретранслируемый** канал.
- **Свои трекеры обнаружения**: комнаты, ссылки доступа и удалённые трансляции
  используют публичные WebRTC-трекеры для первоначального соединения, без передачи
  файлов или открытого содержимого. Укажите свои в «Настройки → Общий доступ»;
  недоступная запись заменяется публичным набором, чтобы комната могла объявить о себе.

### Совместные игры

- **Виртуальная локальная сеть**: ведущий запускает сессию, допущенные участники
  получают виртуальные адреса и прямой зашифрованный канал. Широковещательные
  и multicast-пакеты передаются между ними, чтобы игры находили друг друга
  без ручного ввода адреса. Игровой сервер комнаты объявляется так же.
  Ретрансляция включается отдельно и не отображается как здоровый прямой канал.
  Пока **только Windows**; остальные участники сохраняют файлы, чат и голос.
- **Выделенный сервер в комнате**: установка, запуск, остановка и консоль.
  Общие моды можно копировать на сервер с согласия пользователя.
  Сейчас реализован модуль Minecraft; остальные обозначены как будущие.

### Голос и демонстрация экрана

- **Голос без серверов приложения**: сеть прямых WebRTC-соединений между участниками комнаты.
- **Нейросетевое шумоподавление**: RNNoise в WASM AudioWorklet,
  режимы «выключено», «стандартное», «усиленное» для подавления клавиатуры и вентиляторов.
- **Демонстрация экрана по запросу**: передача экрана или окна,
  дополнительный **системный звук** с эхоподавлением.
- **Глобальная push-to-talk**: клавиша работает и при свёрнутом приложении.
- **Управление устройствами**: выбор микрофона и вывода, усиление входа,
  громкость, чувствительность активации голосом и **прослушиваемый тест микрофона**
  через выбранное устройство.
- **Состояние соединения**: хорошее, среднее, плохое качество и переподключение на каждой карточке.

### Автоматизация и сеть

- **Планировщик** ограничений скорости по времени, включая интервалы через полночь.
- **Отслеживаемая папка** автоматически добавляет появившиеся `.torrent`.
- **Списки блокировки IP** загружаются по URL и применяются к движку.
- **Расширенные настройки движка**: DHT, число соединений, порт.
- **«Пауза всем» / «Возобновить всё»** на панели и в меню трея.

### Работа с приложением

- **Фоновый режим по желанию**: включите закрытие в трей, чтобы загрузки продолжались
  после закрытия окна. Окно открывается снова через ярлык или трей.
  По умолчанию закрытие завершает приложение.
- Автозапуск, закрытие и сворачивание в трей, системные уведомления о завершении.
- **Два основных пространства**: переключатель **«Загрузки | Комнаты»**,
  постоянная строка состояния со скоростью, пирами и текущими слушателями.
- **Темы оформления**: тёмная, светлая и системная на тёплой палитре **Ember**
  с логотипом-крыльями W. **Редактор темы** с параметрами двух режимов,
  импортом и экспортом JSON и проверкой значений, чтобы чужая тема не ломала интерфейс.
- **Настраиваемые горячие клавиши**.
- **Языки интерфейса**: английский и русский.
- Экспорт и импорт настроек.

### Приватность и анонимность

- **Панель сетевой видимости**: внешний IP, который видят пиры, провайдер,
  местоположение и состояние VPN с цветовой оценкой.
- **Предупреждение об утечке IP**: если адрес торрент-соединений похож на адрес
  обычного провайдера, а не VPN. Проверки выполняются только при открытии или
  обновлении панели, без фонового трафика.
- **VPN kill-switch** ставит торренты на паузу при отключении VPN,
  проверяет соединение при запуске и действует также на комнаты.
- **Рекомендуемый пресет приватности**, временный идентификатор пира,
  очистка чувствительных данных в логах, удаление данных при выходе,
  открытие и очистка журналов.
- **Шифрование секретов на диске** средствами ОС: DPAPI / Keychain / libsecret.

### Безопасность приложения

- Изоляция контекста, renderer в песочнице, отключённая интеграция Node,
  типизированный IPC-мост.
- Content-Security-Policy и ограничения навигации в production-сборках.
- Локальный сервер потоков отклоняет запросы с чужого origin и DNS rebinding,
  чтобы сторонняя страница в браузере не прочитала ваш поток.

### Статус безопасности

Протокол комнат Havvn использует стандартные механизмы: **AES-256-GCM** для
содержимого и чата, **Ed25519** для личности участников, авторства конфигурации
и передачи владения. Но их объединение в протокол — **собственная разработка автора,
не прошедшая независимую проверку безопасности или аудит**. Он рассчитан на конкретную
угрозу: владелец кода приглашения без предоставленного членства не должен подделывать
конфигурацию, выдавать себя за другого участника или подменять ключ содержимого.

Протокол не проектировался для противодействия хорошо оснащённому атакующему
и не проверялся в таких условиях. Шифрование защищает от случайного перехвата
и других пиров, но не является гарантией для сценариев, где ошибка имеет серьёзные
последствия. Если найдёте уязвимость, создайте issue — автор предпочитает узнать о ней.

## Архитектура

### Состояния загрузки

Жизненный цикл проверяется в `shared/state-machine.ts`:

```text
QUEUED → DOWNLOADING → SEEDING ⇄ COMPLETED
   ↓         ⇅           ⇅
   └──────→ PAUSED ─────→ COMPLETED

Ошибка передачи → ERROR → QUEUED / DOWNLOADING (повтор)
Любое состояние → REMOVED
```

Недопустимые переходы отклоняются, чтобы состояние оставалось согласованным.

### Хранение данных

Загрузки, настройки, ленты, правила и источники хранятся локально через
**electron-store** в JSON. Прогресс записывается с задержкой и объединением изменений,
чтобы уменьшить дисковую нагрузку; загрузки восстанавливаются после перезапуска.
История просмотра, позиции и предпочтения плеера/поиска хранятся на этом компьютере
в localStorage интерфейса. Источники используют отдельные постоянные браузерные сессии,
не импортируя cookies или пароли из обычного браузера.

### Процессы и безопасность

- Renderer изолирован и работает в песочнице без интеграции Node.
- Минимальный типизированный preload-мост предоставляет только нужный интерфейсу IPC.
- Production-сборки применяют Content-Security-Policy и блокируют переходы основного
  интерфейса на внешние сайты; внешние ссылки открываются в системном браузере.
- Окна входа источников используют собственные сессии в песочнице и разрешают
  навигацию верхнего уровня только на заданные origin. HTTPS-ресурсы страницы
  и ресурсы проверок Cloudflare доступны внутри окна, без preload API приложения.

### Журналы

Структурированные логи записываются в каталог `logs/` приложения с ежедневной
ротацией, уровнями важности и автоматическим удалением старых файлов.

## Известные ограничения

- **Лимиты скорости** обычных торрентов обеспечивает нативный движок.
  В комнатах и ссылках доступа WebTorrent ограничивает трафик по возможности;
  для строгого контроля используйте средства ОС.
- **Статистика пиров** комнат и ссылок приблизительная: WebTorrent сообщает
  общее число и не всегда разделяет сидов и личеров.
- **VPN и утечки IP** определяются эвристически по интерфейсам и IP/провайдеру.
  Это дополнительная защита, а не гарантия; kill-switch самого VPN надёжнее.
- **Прокси** для трафика пиров не поддерживается — для сетевой приватности нужен VPN.
  Прокси источника действует только на поиск и получение `.torrent`;
  профили с авторизацией пока не поддерживаются.
- **Доступ к сайтам**: сессия входа не гарантирует прохождение ограничений сайта
  или браузерных проверок. Старый Python-плагин нужно обновить для общего подключения;
  прежний режим Legacy сохраняет собственную сеть и авторизацию.
- **Внешнее воспроизведение**: VLC / mpv устанавливаются отдельно. Незавершённому
  потоку нужны выбранный файл, активная загрузка и работающий Havvn.
  История и внешний плеер не возобновляют остановленные или исключённые загрузки.
  Остановка внешнего потока не останавливает торрент. Позицию возвращает только mpv.
- **Предзагрузка серий** пока работает только в Classic/WebTorrent,
  внутри одного торрента и при известной длительности воспроизведения.
- **Удалённый просмотр WebRTC** экспериментален, зависит от NAT и может не подключаться
  в некоторых сетях.
- **Комнаты при строгом NAT** обычно соединяются напрямую, через IPv6/STUN или
  другого участника. Если абсолютно все находятся за строгим симметричным NAT
  и никто не доступен извне, нужен **свой TURN-сервер** хотя бы у одного участника.
- **Просмотр во время загрузки в комнатах** поддерживает комнаты без шифрования
  файлов и браузерные форматы; остальное воспроизводится после полной загрузки.
- **Браузерные гости** получают чат, голос и совместный просмотр. Запись файлов,
  виртуальная сеть, игровой сервер и просмотр зашифрованных файлов недоступны.
  Ведущий должен держать Havvn открытым.
- **Виртуальная сеть — только Windows**. На macOS и Linux участники могут обмениваться
  файлами, общаться и использовать голос, но не подключаться к туннелю.
- **Игровые серверы**: пока только Minecraft; сервер работает на компьютере ведущего.

## Участие в разработке

CI запускается на push в `main` и pull request (`.github/workflows/ci.yml`).
Проверка типов, тесты и сборка обязательны; линтер работает как рекомендательная
проверка. Перед PR выполните `npm run typecheck`, `npm test` и `npm run build`.

`npm run build:guest`, также входящей в `npm run build`, и должна быть включена
в коммит для публикации через GitHub Pages.

и китайскую (`README.zh-CN.md`, упрощённый китайский) версии.
