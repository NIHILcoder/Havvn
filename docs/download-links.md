# Добавление загрузки по ссылке

На странице загрузок есть явная кнопка **«Добавить ссылку»** рядом с
**«Добавить торрент»**. Она принимает один magnet с v1 infoHash (hex/base32)
или HTTP/HTTPS-адрес торрент-файла. Пробелы по краям удаляются; некорректный
ввод остаётся в диалоге с доступным сообщением об ошибке. Вставка не читает
буфер обмена автоматически и не создаёт загрузку до подтверждения.

После «Продолжить»/Enter открывается существующий выбор файлов, категории и
папки. Если метаданные недоступны, остаётся явная команда «Добавить всё равно»:
пустая маска означает все файлы. Ошибка добавления сохраняет подтверждение для
повтора; синхронная защита блокирует два добавления при быстрых нажатиях.

## Ошибка последовательной загрузки магнета

Предварительный просмотр Native использует временную запись daemon, удаляя её
после получения метаданных. Следующее настоящее добавление магнета начинает
снова без метаданных. Раньше команда настроек всегда передавала
`sequential_download_from_piece: 0`, даже при `sequential_download: false`.
Transmission отклонял её: `piece to sequentially download from is outside
pieces range`. Запись уже была создана, но запуск не выполнялся.

Теперь режим последовательной загрузки передаётся сразу, а сброс позиции в
часть 0 — только при полученных метаданных и положительном количестве частей.
Этот путь общий для добавления, восстановления, переключения режима и возврата
настроек после просмотра. Настройки последовательности возвращаются к началу
после просмотра, когда диапазон частей существует.

## Объём и скорость отдачи

Поле «Отдано» отображает `uploadedBytes`, то есть накопленный объём отправленного
по этому торренту в байтах, а не байты в секунду. «Скорость» при скачивании
отображает `downSpeedBps`, а при раздаче — `upSpeedBps`. Лимиты применяются к
скорости; сравнение накопленного объёма с мгновенной скоростью не проверяет
соблюдение лимита. Проверка выше подтверждает передачу настроек daemon, а не
измерение пропускной способности внешней сети пользователя.

Нулевой лимит скорости отдачи означает «без ограничения», а не запрет отправки.
