## Отложенные пункты

- [ ] На двух Windows-ПК с одинаковой новой сборкой проверить настоящую игру

## Какие условия нужны

Сборку пакетов, изолированную установку Windows, длительную загрузку и работу
установленного внешнего плеера можно проверять на одном ПК. Для чистой ОС
потребуется отдельная система или подходящая виртуальная машина. Сборка
Linux-пакета требует подходящего окружения сборки; его успешная сборка сама
по себе не подтверждает работу на физическом Linux-ноутбуке.

Реальные соединения между разными сетями, звук и захват экрана ноутбука,
а также работу телевизора не заменяет запуск нескольких профилей на одном ПК.
Их проверяем после возвращения пользователя домой на одной и той же итоговой
версии приложения. Предыдущие успешные ручные проверки сохраняются как
результаты прежней версии, без автоматического переноса на новый пакет.

Порядок продолжения: Linux-пакет и чистая Windows → два устройства через разные
сети → восстановление после сна/смены сети → ночной прогон.
