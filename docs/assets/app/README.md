# Application screenshots

These images show Havvn's React application with its actual styles, using isolated
test profiles and synthetic data. They contain no user's downloads or room content.

- `downloads.png` and `light.png`: the current downloads page in Graphite and
  Paper. Three sample transfers use Ubuntu, Big Buck Bunny and a fictional project
  archive. Captured at 1440 × 900 with the existing application UI fixture.
- `workspace.png`: the room workspace and document editor, captured with an
  isolated collaborative-workspace fixture and sample notes.

The first-screen caption identifies the data as demonstration content. The separate
interactive preview further down the page is an HTML demo, not a running client.
