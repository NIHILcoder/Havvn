# Управление просмотром демонстрации

ПКМ по изображению и кнопка «…» в заголовке открывают одно меню. Доступны отдельное окно, полноэкранный режим, показ изображения целиком или заполнение области с обрезкой краёв. В комнате также доступно расширение просмотра на всю ширину.

Отдельное окно можно перемещать и изменять в размерах. Кнопка возврата и закрытие самого окна возвращают просмотр в комнату. Переключение на общие файлы сохраняет просмотр. Закрытие просмотра завершает только этот просмотр; остановка собственной демонстрации остаётся отдельным действием.

Для своей трансляции меню открывает разрешение, FPS и битрейт. Настройки применяются к существующему видеотреку и отправителям с сохранением голосового соединения и локального просмотра. Ошибка оставляет действующую трансляцию и позволяет повторить изменение. Для чужой трансляции доступны локальная громкость и отключение системного звука отдельно от микрофона участника; менять качество захвата другого участника нельзя.

Видео и React-портал сохраняют один DOM-контейнер при переносе между окнами. Локальное WebRTC-соединение не пересоздаётся. Перед уничтожением дочернего окна контейнер синхронно возвращается в основной документ. Меню и настройки используют документ владельца, включая верхний слой полноэкранного режима.

Для обновления требуется полный перезапуск `npm run dev`: добавлены IPC-команды и разрешённое имя окна. Ctrl+R обновляет только интерфейс.

Проверки: `npm run test:screen-view-ui`, тесты `room-voice-recovery`, `room-manager`, `screen-share`, `player-windows`, `popout`; прежние `smoke-screen-actions.cjs` и `smoke-screen-share-settings.cjs`. UI-стенд использует настоящую локальную передачу WebRTC с генерируемым canvas, изолированный профиль, sandbox и context isolation. Он не захватывает рабочий стол или микрофон. Проверка на двух физических устройствах и фактическое качество конкретного экрана этим стендом не подтверждаются.
