# Сохранённые виды загрузок — PER-01

Реализованы 23 октября 2026 года. Над списком загрузок появились выбор вида, «Условия отбора» и «Сохранить текущий вид». Используются общие Button, Select, Modal и подтверждение удаления Havvn.

## Работа с видами

1. Задайте состояние, категорию, подстроку имени/пути и границы размера в «Условиях отбора». Строка поиска загрузок управляет той же подстрокой имени.
2. Выберите сортировку и компактный/подробный режим. Сохраните вид под именем; закрепление в боковой панели включено по умолчанию.
3. Открывайте его из списка, закреплённого пункта Sidebar или палитры `Ctrl+K`. Условия вычисляются по текущим загрузкам.
4. Изменение фильтров, сортировки или режима отмечается как несохранённое. «Обновить вид» явно заменяет сохранённую конфигурацию; «Сохранить текущий вид» создаёт другую. Переименование и закрепление не сбрасывают текущие несохранённые изменения.
5. Удаление вида проходит через общий диалог подтверждения и удаляет только подборку. Быстрые фильтры Sidebar сохраняются и выходят из сохранённого вида.

Последний выбранный вид восстанавливается после запуска. Сам вид хранит условия, сортировку, режим и закрепление; копии загрузок не сохраняются. Текущие несохранённые изменения не заменяют его конфигурацию.

## Условия

Все условия выполняются одновременно. Состояния соответствуют существующим быстрым фильтрам: «Загружаются» включает очередь, «Завершены» — раздающиеся загрузки. Категория выбирается по точному ID; «Все категории» и «Без категории» различаются.

Поиск имени и пути не учитывает регистр, нормализует Unicode и `ё/е`; разделители `\\` и `/` в пути равнозначны. Это поиск подстроки, без регулярных выражений и исполняемых выражений. Размер вводится в МиБ (`1024²` байт), хранится целым числом байтов и сравнивается включительно. Пустое поле снимает ограничение, неизвестный размер не проходит заданные границы. Возраст раздачи в первый набор не включён.

Удалённая категория не превращается во «Все категории»: ID остаётся в условиях, интерфейс показывает пояснение. Вид продолжает отбирать записи с этим ID; если загрузки больше на него не ссылаются, результат пуст. Категорию можно заменить через условия и обновить вид.

`Ctrl+A` выбирает текущий результат, включая строки вне экрана. При изменении условий скрытые загрузки снимаются с выделения. Клавиши страницы уступают открытым диалогам. Адресуемый переход к конкретной загрузке выходит из вида и снимает ограничения, чтобы объект был виден.

## Хранение и перенос

Числовые поля условий используют общий NumberInput с тематическими стрелками.
Пустое значение остаётся необязательной границей; дробные МиБ можно вводить
и увеличивать стрелками без ошибки `step="any"`. После правок 24.10.2026
сценарий Electron повторён: 23 проверки, включая эти случаи, прошли.

Версионированный каталог `{ version: 1, views, activeId }` хранится под `havvn.download-views.v1` в renderer localStorage. Предел — 64 вида, название — 80 символов, строка имени — 200, путь — 1024. Дубли имён без учёта регистра и дубли ID отклоняются. Набор полей и значения сортировки/режима проверяются общей схемой.

Модель одна на renderer. Сохранение сначала записывает валидный каталог, затем уведомляет интерфейс. При отказе записи прежний вид остаётся действующим; повреждённые данные не перезаписываются пустым каталогом. Временные фильтры доступны независимо от сохранения. Перечитываются изменения хранилища и завершение переноса настроек.

Виды и выбранный ID входят в раздел переноса «Панели, интерфейс и виды загрузок». Выбор другого раздела их не затрагивает. Полный новый снимок с явным `null` очищает каталог. Старые файлы v2 и старые журналы восстановления без этого ключа поддерживаются: отсутствие поля сохраняет уже существующие виды. Обязательные прежние ключи по-прежнему проверяются.

## Общая модель и проверки

Предикат подготавливается при изменении условий и применяется к `downloadsModel`. Отдельных подписок на движок для видов нет. Сортировка прогресса/скорости использует прежний общий stats selector; для имени/даты он не нужен. Список остаётся виртуальным.

- Общий `npm test`: 3797 тестов в 278 Vitest-файлах и 8 тестов запуска прошли. После этого отдельно добавлен и проверен тест восстановления старого журнала с сохранением новых видов; целевые проверки также повторены.
- `npm run test:download-views`: 44 проверки схемы, предикатов, хранения, отказов, переноса и палитры. Дополнительно прошли 8 тестов preload-координатора переноса, включая старый журнал.
- `npm run test:download-views-ui`: 20 групп проверок настоящих App, TitleBar, Sidebar, Modal, Select и виртуального списка в изолированном Electron. Проверены 1000 загрузок, сочетание условий, живое обновление состава/выделения, сохранение/переименование/закрепление/удаление, отсутствующая категория, палитра, быстрые фильтры, перезапуск renderer, недопустимые размеры, обе локали и окно 760 px с Sidebar.
- На 1000 записях одновременно монтировались 18 строк; подписка на статистику движка оставалась одной. Синтетический замер 100 проходов фильтра сохранён в `dist/download-views-ui/report.json`. Он измеряет локальный предикат; загрузки и сетевой движок в UI-проверке подменены. Бюджеты OPT-02 и сравнение реальной сетевой нагрузки остаются отдельной задачей.
- Production-проверка переноса между профилями прошла 8 фаз Electron: экспорт, импорт/частичный импорт, перезапуск, возврат и восстановление прерванной операции. В исходный и целевой профиль добавлены разные виды; полные снимки проверяют их перенос и возврат, импорт только хоткеев сохраняет целевой каталог.
- Повторно прошли 45 проверок геометрии списка, 21 группа проверок палитры, 15 — центра событий и 10 — интерфейса переноса настроек.
