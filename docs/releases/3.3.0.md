# Havvn 3.3.0 — общая локальная сборка

Один набор исходников и функций для Windows x64 и Debian 13 x64. Общие папки,
файловый редактор и совместные документы доступны при обычном запуске приложения.
Для их появления больше не требуется `HAVVN_FILE_SYNC=1`. Код этих функций уже
находился в основной рабочей копии; в 3.3.0 изменён режим их включения.

В сборку входят:

- Общие папки комнаты и редактор текстовых файлов, история, разрешение конфликтов
  и восстановление версий. Локальная папка подключается явно; режим применения
  изменений и права участников сохраняют существующие подтверждения.
- Совместные документы и встроенный редактор с сохранением и снимками состояния.
- Настройки демонстрации: 480p–4K, 15/30/60 FPS, лимит битрейта и системный звук
  на Windows. Общий предел трафика продолжает действовать. Просмотр допускает
  до 60 FPS; фактическое качество зависит от источника, сети и устройства.
- Исправления запуска демонстрации, вёрстки переподключения и отступов уведомлений.
- Исправление общих выпадающих списков: реальный клик теперь применяет значение
  до закрытия меню. Оно относится в том числе к языку, оформлению и фону.
- Накопленные изменения загрузок, обработки ошибок и безопасности текущей
  рабочей копии.

Обычный запуск из исходников:

```powershell
cd D:\reps\Havvn\Havvn
npm run dev
```

Отдельная пустая тестовая копия со своими настройками, комнатами и торрентами:

```powershell
$env:TH_INSTANCE='test-330-clean'
npm run dev
```

Для нового чистого профиля выбирается новое имя. Ранее запущенный dev-процесс
нужно завершить перед повторным `npm run dev`, чтобы освободить его порт.
Доступно диагностическое отключение общих папок через `HAVVN_FILE_SYNC=0`.

Локальные результаты проверки и происхождение файлов находятся в
`artifacts/unified-3.3.0/` и связанных журналах `artifacts/unified-3.3.0-*.log`.
Прежние подтверждения из `docs/rooms-release-acceptance.md` относятся к своим
снимкам продукта и не заменяют проверку нового кандидата. Работа через разные
физические сети, публичные трекеры ноутбука и совместная правка на физической
паре Windows ↔ Linux остаются отдельными проверками. Локальные профили на одном
ПК не подтверждают их прохождение.
