# Downloads: переключение вида и высота строк

Компактный вид позволяет раскрывать отдельные торренты. Выбор общего вида
сбрасывает эти раскрытия; повторное нажатие «Компактный вид» сворачивает все строки.
Кнопки и Ctrl+P используют один обработчик.

При смене вида виртуализатор сбрасывает сохранённые высоты, пересчитывает позиции
по оценкам и измеряет смонтированные строки в `useLayoutEffect`, до отрисовки кадра.
Один `measure()` недостаточен: карточка, раскрытая вручную, может сохранить ту же
высоту, поэтому `ResizeObserver` не отправит новое измерение. После сброса кеша
нужно также пересчитать позиции перед измерением, иначе виртуализатор сравнит
размер со старой высотой и пропустит неизменившуюся карточку.

Отдельная кнопка обновления списка убрана: `downloadsModel` получает статистику
через IPC и сверяет полный список каждые пять секунд. Внутренние обновления после
добавления, удаления и действий с торрентами сохранены.

Проверка: `npm run test:download-layout`. Она запускает настоящий `DownloadsPage`,
компоненты строк, Zustand и TanStack Virtual в скрытом окне Electron с отдельным
профилем и тестовыми данными. Проверяет геометрию строк, сворачивание, Ctrl+P,
прокрутку, изменение ширины, длинные ошибки, удаление строки и автообновление.
Отчёт и снимки окна: `dist/download-layout/`. Рабочие загрузки не используются.
