# Прогресс файлов и завершение загрузки

Этапы получения метаданных и проверки диска теперь отображаются отдельно
от готовности файлов: см. [долгие операции UX-03](long-operations.md).
Native использует `recheckProgress`, Classic показывает неизмеренную проверку.

`FilePreview` обновляет список раз в секунду после завершения предыдущего запроса.
Закрытие окна и смена торрента отменяют применение старых ответов. После ошибки
последний список остаётся видимым, а следующий запрос может восстановить связь.
Общий процент учитывает выбранные файлы; байтовые значения нормализуются в
диапазон от нуля до размера файла.

В WebTorrent прогресс отдельного файла считается по пересечению его диапазона
с проверенными кусками. Прямое использование `File.downloaded` версии 3.0.21
давало отрицательный результат для маленького файла внутри частично полученного
куска и теряло последний полный кусок при совпадении конца файла с границей.
Исправление находится в адаптере Havvn, без редактирования `node_modules`.
Transmission использует свои текущие `fileStats.bytesCompleted` с проверкой границ.

Живые показатели списка имеют приоритет над более редкими снимками базы.
Счётчик «Получено по сети» хранит трафик за все сеансы, включая повторные передачи;
он не используется для вычисления процента готовности файлов.

При возобновлении Transmission Havvn ждёт фактического состояния `Stopped`.
Одного ответа на `torrent-stop` недостаточно: сразу после него движок может ещё
сообщать `Downloading`, проигнорировать `torrent-start`, а затем остановиться.
Ожидание ограничено десятью секундами и отменяется новой паузой. Подтверждение
запуска отслеживается отдельно; потерянный запуск повторяется ограниченное время.

Проверки:

- `npm run test:download-progress` — реальные классы WebTorrent, границы файлов,
  отображение Transmission и гонки снимков, а также настоящие многосоставные
  загрузки обоих движков через локальные TCP-соединения с паузой/возобновлением.
  Проверяется готовность 100%, единственное уведомление о завершении и побайтовая
  целостность, включая файл на 61 байт и файл с концом на границе куска.
- `npm run test:file-progress-ui` — настоящий React-диалог в Electron: автообновление,
  нечисловые/отрицательные счётчики, медленный IPC, смена торрента, ошибки,
  восстановление связи и отмена таймера. Снимки и отчёт: `dist/download-progress/`.

Тесты используют отдельные профили и собственные файлы. Они не проверяют
конкретную пользовательскую раздачу или внешних пиров.
