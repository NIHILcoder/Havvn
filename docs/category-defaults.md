# PER-04: параметры категорий

Реализовано 23 октября 2026 года.

## Настройки и поведение

В «Настройки → Загрузки» добавлен редактор категорий: создание, выбор,
переименование, значок, цвет, удаление и сброс параметров к общим настройкам.
Необязательные `Category.downloadDefaults` содержат:

- `savePath` — каталог новых загрузок;
- `seedRatioLimit` — лимит коэффициента раздачи;
- `seedTimeLimitMinutes` — время раздачи в минутах;
- `paused` — добавление на паузе;
- `sequentialDownload` — последовательный выбор частей.

Отсутствующее значение наследуется. Пустой каталог и пустой числовой ввод
убирают переопределение. Ноль означает отсутствие лимита, `false` явно выключает
параметр. Лимиты валидируются: коэффициент 0–10 000, время — целые минуты
0–52 560 000. Старые категории без новых полей работают как прежде.

Общий приоритет: **явное значение запроса → категория → общие настройки**.
У общих настроек по-прежнему нет отдельного старта на паузе или последовательного
режима: их исходные значения — `false`. Глобальные лимиты раздачи сохраняют
живое наследование; лимиты категории или явного запроса копируются в запись.
Последующие изменения категории не меняют параметры уже добавленных загрузок.

В ручном добавлении доступны категория и наследуемый выбор старта. Путь,
выбранный пользователем, имеет приоритет. Полный запрос добавления также
поддерживает явные лимиты и последовательность. Предпросмотр показывает
итоговые значения и источник каждого из них. Он есть в ручном добавлении,
поиске, быстром поиске, редакторах RSS-ленты и правила. Для правила с несколькими
лентами можно выбрать ленту предпросмотра: её каталог/категория могут отличаться.

В RSS сначала собирается явный запрос: правило → лента. Для оставшихся
параметров применяется категория → общие настройки. Явный `addPaused: false`
не теряется. В формах добавлен выбор наследования, запуска и паузы.

## Где выполняется расчёт

`shared/category-defaults.ts` содержит общий расчёт и валидацию, используемые
предпросмотром и main. `TorrentManagerProxy.addDownload` читает актуальные
категории и настройки, разрешает параметры и проверяет каталог перед отправкой
в host. Поэтому ручное добавление, поиск, RSS, watch folder и web remote
проходят одну границу. Неизвестная категория даёт ошибку вместо тихой подмены.

Каталог должен быть абсолютным и проходить существующую проверку путей.
При необходимости он создаётся; затем проверяются тип и доступ на запись.
Недоступный каталог отклоняется до обращения к движку и создания записи.
Это предварительная проверка: доступ может измениться после неё, поэтому
обычная обработка ошибок записи движка остаётся необходимой. При отказе
ручное добавление сохраняет выбор файлов, категории и пути для повторной попытки.

Classic и Native получают уже разрешённые параметры. Они сохраняются при
создании записи. Native применяет коэффициент раздачи и последовательность
к остановленному торренту до первого запуска и повторно при его добавлении
в daemon. Classic использует сохранённую стратегию и учитывает явный нулевой
лимит независимо от ненулевого общего значения.

Смена категории существующей записи меняет только ссылку на категорию.
Удаление категории снимает её с записей и очищает ссылки RSS. Пути файлов,
выбор файлов и сохранённые лимиты загрузок не заменяются.

## Перенос настроек

Новые поля включены в прежний формат переноса как необязательные значения.
Старые файлы остаются допустимыми. Валидация одинакова для редактора, main
и импорта. Изменение только параметров категории учитывается в плане импорта;
нативный предпросмотр показывает значения до и после, включая наследование.
ID существующей категории сохраняется при редактировании. При импорте каталог
не создаётся: его доступ проверяется при последующем добавлении загрузки.

## Проверки

- `npm run test:category-defaults`: 89 тестов прошли. Проверяются приоритеты,
  ноль/false, старые категории, снимок параметров, валидация, перенос, реальная
  проверка каталога и методы Native на подменённой RPC-границе.
- `npm run test:category-defaults-integration`: 12 проверок прошли с настоящими
  Classic/Native, main store, proxy и путём добавления RSS. Отдельный профиль,
  локальные торренты и отключённый поиск внешних пиров. Межпроцессный порт proxy
  заменён прямой передачей запроса настоящему менеджеру. Проверены сохранение
  до запуска, реальные параметры daemon и стратегия Classic, явные значения,
  наследование RSS, отказ каталога до dispatch, неизменность существующих
  загрузок и очистка ссылок RSS при удалении категории.
- `npm run test:category-defaults-ui`: 13 проверок прошли в настоящем Electron
  с реальными компонентами и IPC/store категорий. Граница предпросмотра
  метаданных файла подменена. Проверены создание/сохранение/сброс, предпросмотр,
  запрос с явным `false`, повтор после отказа каталога, несколько RSS-лент,
  ширина 520 px и en/ru. Снимки просмотрены:
  `dist/category-defaults-ui/editor-wide.png`, `editor-narrow.png`.
- После изменений предпросмотра импорта прошли ещё 37 профильных тестов;
  дополнительно прошли 49 проверок импорта, жизненного цикла, лимитов и поиска
  настроек. Эти наборы пересекаются с основным профильным набором.
- Общий прогон: 3872 из 3873 тестов прошли. Один тест `guest/mesh-chat.test.ts`
  превысил 5 секунд. В отдельном повторе все 8 тестов этого файла прошли;
  изменение гостевого чата для устранения таймаута не выполнялось. Все 8
  проверок запуска также прошли. Чистый одновременный общий прогон не заявляется.
- Typecheck Electron/renderer/guest и сборки прошли. Renderer сохраняет три
  предупреждения webpack о размере и runtime чанков. ESLint новых модулей
