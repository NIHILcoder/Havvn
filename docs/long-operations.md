# Долгие операции — UX-03

Дата: 23 октября 2026 года.

Общий контракт находится в `shared/operations.ts`: этап, состояние, измеренный
прогресс либо `null`, причина ожидания, поддерживаемые действия и последний
подтверждённый результат. Это представление настоящего состояния владельца;
оно не заменяет состояния загрузки, комнаты или игрового сервера.

## Где используется

- Загрузки: очередь, метаданные, проверка диска, передача, пауза и завершение.
  Наблюдение передаётся в существующем `DownloadStats.operation`, без отдельного
  таймера или подписки для каждой строки. Компактная строка показывает этап
  и подсказку, раскрытая — объяснение и следующий шаг.
- Экспорт настроек: выбор места, подготовка, атомарная запись, подтверждённый
  успех, ошибка или отмена выбора файла. Основной процесс хранит последнее
  состояние текущего сеанса; повторное открытие настроек читает его через
  доверенный IPC. Подписка передаёт только сигнал обновления.
- Диагностика комнаты: адаптер существующих наблюдаемых фаз соединения.
  Готовность управляющего канала не означает готовность всех файлов, голоса
  или LAN. Сбой отдельного трекера не превращается в отказ всей комнаты.
- Игровой сервер: запуск ждёт готовности процесса, остановка — его завершения.
  Общая карточка использует статус супервизора, а не ответ о принятой команде.
  При установке показывается этап и действующая кнопка отмены; прежний взвешенный
  процент разных шагов не выдаётся за измеренный общий объём работы.

## Прогресс и ожидание

Native отдельно запрашивает `recheckProgress`; `percentDone` остаётся долей
готовых выбранных файлов. Ожидание проверки (`CheckWait`) не показывает процент
уже готовых файлов. Проверка остановленных/готовых данных видна без ложного
возобновления скачивания и без уведомления о новом завершении.

Classic определяет этап по `metadata` и `ready`. WebTorrent сообщает проверенные
**валидные** куски, а не количество **проверенных** кусков: при отсутствующих или
повреждённых данных из этого нельзя получить процент проверки. Поэтому проверка
Classic остаётся без процента. Таймаут метаданных снимается на `metadata`, до
долгой проверки диска; сама проверка не ограничивается таймаутом получения метаданных.

Нулевой поток с подключёнными пирами обозначается как неподтверждённая причина
ожидания. Отсутствие пиров, очередь, пауза и отсутствие свежего наблюдения
различаются. В объяснениях доступны действующие следующие шаги: дождаться,
открыть файлы/трекеры, проверить лимит, поставить на паузу или возобновить.

`ProgressBar` поддерживает неопределённый прогресс: без числа и без
`aria-valuenow`. Завершённая отмена без измеренного объёма не оставляет полосу
ожидания. Новые тексты доступны на русском и английском.

## Повторы, отмена и поздние ответы

Экспорт имеет одного владельца с идентификатором попытки и монотонной ревизией.
Состояние завершённой попытки нельзя заменить поздним успехом или ответом старой
попытки. Успех подтверждается после записи, синхронизации и переименования
временного файла. Повторные экспорты/импорты блокируются существующим владельцем
переноса. Отмена в системном диалоге — подтверждённая отмена выбора; после начала
атомарной записи кнопка отмены не предлагается.

Наблюдатель renderer отбрасывает старые ревизии и ответы после размонтирования.
Потеря IPC сохраняет последнее наблюдение и показывает, что обновление недоступно;
она не считается отменой работы. Закрытие настроек также не отменяет экспорт.

В Classic события заменённого/удалённого экземпляра не меняют новую попытку.
Ошибка блокирует `ready`/`done` ещё до ответа базы, старое подтверждение статуса
не заменяет новое, закрытие экземпляра завершает ожидание. Ожидаемое закрытие
при восстановлении не становится новой ошибкой строки. Пауза остаётся паузой,
включая истечение ожидания метаданных.

Повторные запросы проверки объединяются на владельце для обоих движков.
Уже идущая проверка не перезапускается, пункт повторной проверки недоступен
в контекстном меню при наблюдаемой проверке. Доступность общих действий сервера
учитывает роль; штатная авторизация остаётся у владельца подсистемы.

## Проверка

- `npm run test:operations` — владение и запоздалые результаты, адаптеры, гонки
  renderer, реальные методы менеджеров с подменённой границей движка, IPC,
  повторные проверки и отображение строки.
- `npm run test:operations-ui` — настоящие компоненты в Electron: виртуальный
  список, измеренная и неизмеренная проверка, метаданные, ширина 520 px;
  настройки с ожиданием и отменой экспорта после размонтирования;
  диагностика комнаты, включая узкий диалог и устаревший ответ.
- `npm run test:settings-transfer-integration` — настоящий sandboxed preload,
  IPC и отдельные профили. Дополнительно проверяются подписка на статус,
  блокировка повторного экспорта, отмена и чтение подтверждённого результата.
- Общий прогон: 3829 тестов Vitest и 8 тестов запуска прошли; в нём выполнялись
  настоящие многосоставные Native/Classic загрузки через локальные соединения.
  После финальных правок отдельно прошли 155 проверок, включая поздние
  подтверждения статуса и закрытие экземпляра при восстановлении.
- Повторный прогон `test:download-progress` после защиты статусов: 59 проверок,
  включая четыре настоящие многосоставные загрузки Native/Classic с паузой,
  возобновлением и побайтовой проверкой результата, прошли.
- UI: 53 проверки списка, 13 групп настроек и проверка диагностики комнаты
  прошли. Снимки списка: `dist/download-layout/operations-*.png`;
  экспорта: `dist/settings-transfer-ui/export-cancelled.png`.
- Typecheck Electron/renderer/guest и все три сборки прошли. Renderer сохраняет
  три предупреждения webpack о размере и runtime чанков.
- ESLint новых модулей, адаптеров и затронутых общих компонентов прошёл.
  Проверка больших существующих файлов также показывает прежние предупреждения
  hooks и три ошибки `no-require-imports` в Native manager; эти импорты здесь
  не менялись. Чистый общий lint не заявляется.

Общее состояние экспорта хранится только в текущем сеансе. Долговременные события
экспорта остаются в центре событий UX-02. Здесь не появляется общий журнал всех
операций и не добавляется обещание отменять работу движка по таймауту интерфейса.
Внешние пиры, реальные NAT/VPN, установка игровых серверов из Интернета и
аппаратная скорость проверки диска не относятся к этой локальной приёмке.
