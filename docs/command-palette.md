# Палитра команд — UX-01

Реализовано 23 октября 2026 года. Палитра открывается через `Ctrl+K` или кнопку в заголовке основного окна. Сочетание можно изменить в «Настройки → Горячие клавиши».

## Что доступно

- Переход на любую из существующих страниц, включая поиск контента, RSS и историю просмотра.
- Поиск конкретного параметра по названию, описанию и разделу; переход открывает раздел, раскрывает родительский блок и переводит фокус к параметру.
- Поиск загрузки по названию и ID. Переход сбрасывает фильтр и строку поиска загрузок, выбирает запись по ID и прокручивает виртуальный список к ней. Одинаковые названия не мешают адресации.
- Открытие актуальной папки загрузки.
- Поиск комнаты по названию и ID, повторная проверка сохранённого членства перед открытием.
- Добавление торрента через существующий выбор файла и подтверждение, пауза/возобновление всех загрузок, переключение микрофона и звука активного звонка.

Стрелки выбирают результат, `Enter` выполняет команду, `Escape` закрывает окно. `Tab` остаётся в диалоге. После закрытия фокус возвращается к исходному элементу. Пока команда выполняется, повторный запуск и закрытие блокируются, введённый запрос сохраняется. Недоступные команды показывают причину; удалённый объект вызывает сообщение внутри палитры.

## Локальность и окна

Индекс использует уже загруженные списки и статический каталог настроек. Ввод не вызывает IPC и не отправляет текст источникам контента. Команда «Поиск» открывает существующую страницу; запрос к источникам запускается её отдельным действием.

Палитра и каталог загружаются отдельным React lazy chunk при первом открытии. Метаданные индексируются заново при изменении языка, загрузок, комнат или звонка. Отображаются первые 60 совпадений со счётчиком общего количества; уточнение строки ищет по всему индексу. История запросов не записывается.

В вынесенной панели комнаты и отдельном редакторе темы хоткей открывает палитру в том же окне. Закрытие возвращает фокус в него. Переход к странице или объекту выполняется в основном окне после закрытия палитры, чтобы восстановление фокуса диалога не перебивало переход. Закрытие дочернего окна снимает его регистрацию и закрывает палитру.

## Хоткеи и совместимость

Статические команды используются палитрой и общими хоткеями. `Ctrl+O` теперь открывает существующий выбор `.torrent`, а не только страницу загрузок.

Старые назначения сохраняются. Если пользователь уже назначил `Ctrl+K` другой команде, у палитры не появляется конфликтующее сочетание: остаётся кнопка в заголовке. Назначение занятой комбинации переносит её с предыдущего действия; редактор поясняет это поведение. Изменение применяется сразу. Обычные команды не срабатывают при вводе текста; открытие палитры разрешено из поля. Открытые диалоги и запись хоткея имеют приоритет.

## Устройство

- `renderer/commands/registry.ts`: контракт действия, нормализация/ранжирование, повторное разрешение ID и проверка доступности при выполнении.
- `appCommands.ts`: фиксированный набор разрешённых действий и адресуемые цели навигации.
- `paletteCommands.ts`: локальные настройки, загрузки, папки и комнаты. Произвольного вызова IPC по введённой строке нет.
- `useCommandShortcuts.ts`, `windows.ts`: живые назначения и регистрация окон.
- `CommandPalette.tsx`: combobox/listbox поверх общего `Modal`, сообщения ошибок и защита от повторного запуска.
- `App.tsx`, `SettingsPage.tsx`, `DownloadsPage.tsx`: применение целей навигации и перевод фокуса.
